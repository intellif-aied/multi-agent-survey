最短源码阅读路线

下面保留函数和模块原名，只用于在仓库中搜索；先理解箭头右侧的动作，不必背名字。

AgentTeams

创建配置 → 保存目标 → 持续检查 → 准备身份和文件 → 创建容器 → 启动 Agent。

createWorkerCmd → HTTP API → WorkerReconciler → Provisioner / Deployer → Backend → Worker entrypoint

AgentSpace

创建任务 → 放入队列 → 唯一领取 → 选择执行器 → 写回结果。

createTaskSync → enqueueNativeTaskSync → Daemon claim → ProviderRuntime → AgentRouter → completion

houmao

读取项目定义 → 生成隔离配置 → 启动会话 → 接收任务或邮件 → 停止后可恢复。

project catalog → brain manifest → start_runtime_session → tmux → per-agent gateway / mailbox → relaunch

omnigent

读取 Agent 定义 → 创建根会话 → 启动执行器 → 委派子会话 → 从结果箱取回结果。

AgentSpec → Root Session → Runner Harness → sys_session_send → Child Session → Inbox
